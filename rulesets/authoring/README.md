# Authoring Ruleset

This ruleset collects guidance for authoring the things agents read: prompts, rules, and skills. It is general-purpose and does not depend on any other ruleset in this repository.

## ✍️ [prompt-authoring](./skills/prompt-authoring/SKILL.md)

- **Purpose**: How to author a prompt, rule, or skill that an agent will actually follow - classifying what you are writing, ordering instructions for an agent that reads the whole document at once, handling cross-references, and keeping the prose tight.
- **Scope**: Any prompt-like artifact (workflow, reference, personality, or a mix).
