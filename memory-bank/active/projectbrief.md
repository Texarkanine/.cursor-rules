# Project Brief: Compress and Deduplicate `niko-core.mdc`

## User Story

As a developer and AI agent working across projects, I want `niko-core.mdc` to serve as an omnipresent, high-signal, non-redundant constitutional baseline, so that essential invariants are strictly respected without unnecessary token overhead, repetitive distraction, or mid-task scope creep.

## Requirements

1. **Retain Bedrock Invariants Intact:**
   - Collaborator posture & anti-sycophancy (Core Persona paragraph 2)
   - Clean-break default and explicit public interface identification
   - Strict TDD requirements across planning and execution ("written in blood")
   - Test integrity triage protocol (never hack implementation merely to pass tests)
   - Circuit breaker on repeated verification failures (>2 attempts on the same error)
   - Credential security zero-tolerance rule

2. **Compress Internal Sprawl:**
   - Consolidate repetitive safety/approval directives into a single clear standard: autonomous on reversible actions under version control, confirmation required only for irreversible actions.
   - Consolidate root-cause error diagnosis and circuit breaker into a single cohesive invariant.
   - Consolidate context mapping and ambiguity resolution into lean principles, removing outdated cloud/AWS boilerplate.
   - Consolidate reporting and communication directives into a single structured, low-overhead rule.

3. **Cut Redundant Internal Bloat:**
   - Remove standalone `## Error Handling` section (absorbed into Verification/circuit-breaker).
   - Remove standalone `## Proactive Foresight & System Health` section and `Propose Enhancements` (prevents unsolicited scope creep/refactoring).
   - Remove redundant abstract filler (`Reusability Mindset`, `Evaluate Strategies`, `Strict Rule Adherence`, `Ensure Production-Ready Quality`).

4. **Verify & Validate:**
   - Ensure `rules/niko-core.mdc` remains syntactically valid and cleanly formatted per markdown styling conventions.
   - Run layout and consistency checks (`make test` / link checks).
